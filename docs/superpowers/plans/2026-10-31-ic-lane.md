# IC Lane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A research-only rank IC lane on the cached daily bars: return arrays, the statistic and its checks, a zero-trial re-score of the 64 tested pairs, and the `composite-ic-v1` development gate.

**Architecture:** A new package `agentic_trader/research/ic/` reads the campaigns' cached `CubeBuild`, truncates bars at 2023-12-29 and computes everything from there. `cli/commands/alpha_ic.py` adds the `alpha ic` group. New DSL operators are additive; nothing here runs in the daemon.

**Tech Stack:** Python 3.14, numpy, pandas, scipy (already used by `research/alpha/information.py`), httpx, pydantic, click, `uv`.

**Spec:** `docs/superpowers/specs/2026-10-31-ic-lane-design.md`. Read it first; it holds the reasoning and the exact rules.

## Global Constraints

- Research only: no database, broker orders, registry, Telegram, daemon change, schema change or new dependency.
- Nothing reads a price or label after `2023-12-29`. The window is `2016-08-01` → `2023-12-29`.
- Existing formulas and their identities do not change.
- `EDGAR_USER_AGENT` holds an email address. It never appears in a file, manifest, log line, test fixture or printed output.
- Tests use synthetic bars only and open no network. Tests live under `tests/research/ic/` with an `__init__.py`.
- Implementers stage changes and report; they do not commit. The controller commits.
- Match the surrounding code: `from __future__ import annotations`, frozen dataclasses and `extra="forbid"` models like `research/spread/protocol.py`, ruff C408/PLC0415 strict, mypy clean.
- Each `alpha ic` command refuses an existing output directory and writes `manifest.json` (with `research_environment()` and `authorizes_promotion: false`) before computing, following `research/pooled/null_check.py`.
- zsh does not word-split variables; spell paths out in shell commands.
- Run affected tests with `env -u VIRTUAL_ENV uv run pytest tests/research/ic -q`.

## Review Focus

1. An hourly-scored batch: its target must start from `D+1`'s open, never `D`'s, because its score exists only at 10:00 on `D` (Task 3 and Task 6 tests).
2. Prices after `2023-12-29` that are garbage: every output must be byte-identical to a run on clean prices (Task 3 and Task 5 tests).
3. A formula with mostly NaN or constant scores in many sessions, such as a windowed event field or a short-volume field before 2018-08: sessions count as unavailable and nothing raises; a formula with no evaluated session is left out of the batch mean and counted (Tasks 4 and 6).
4. A name with a missing bar: a missing open at `D+h` is NaN, never the next available open; `mkt_ret` across the symbol's gap compounds SPY over the same gap (Task 3).
5. A hostile SEC response: non-JSON, a blank or missing `sic`, a 404, a redirect to another host. The name is recorded as failed or `unknown`, the others continue, and no response body or user agent reaches the output (Task 2).

- [ ] **Step 3: Implement**

`ts_beta` is rolling covariance over rolling variance of `x`, full window required, NaN at zero variance. `ts_resid_std` is `sqrt(max(var_y − cov²/var_x, 0) · (d−1)/(d−2))`, which is the `ddof=2` residual std of one fit per window. Both register as `OperatorSpec(fn, 3, 3, 2, "matching")`, so mixed units are refused and a price-scaled result fails `require_dimensionless`. Add `mkt_ret` to `FIELD_UNITS` as `(0.0, 0.0)` with the comment pattern of the other lanes. In `panel.py`, validate with `validate_panel`; `cross_sectional_regress_out` fits OLS with an intercept per row on rows where the panel and all regressors are finite.
